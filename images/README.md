# Zdjęcia postaci

Wrzuć tutaj zdjęcia pod nazwami odpowiadającymi graczom:

| Gracz   | Plik                                        |
|---------|---------------------------------------------|
| Margo   | `margo.jpg`                                 |
| Piotrek | `piotrek.webp`                              |
| Antek   | `antek.jpg`                                 |
| George  | `george.jpg`                                |
| Doma    | `doma.jpg`                                  |
| Eryk    | `eryk.jpg`                                  |

Rozszerzenie może być `.jpg`, `.jpeg`, `.png` albo `.webp` — strona sprawdza
je po kolei. Najlepiej wyglądają zdjęcia pionowe w proporcji 3:4
(np. 600 × 800 px).

Dopóki pliku nie ma, w ramce wyświetla się inicjał postaci.

Jeśli zdjęcie źle się kadruje (np. ucina głowę), ustaw graczowi pole `focus`
w `app.js` — np. `focus: 'center top'`.
